# stackflix

Esta app nace como base consolidada de la app StackMusical.
Su principal función es poder acceder mediante la interfaz desarrollada en Dart:Flutter 
al catalogo de pelis de la API TheMovieDataBase, permitiendo de esta forma 
agregar y guardar pelis favoritas o recientes en carteleras de cine 
a una base de datos local. 

⚠️ SPOILER ALERT ⚠️: THIS APP IS CURRENTLY A 'WORK-IN-PROGRESS' 🚧🛑🚨

Algunas de la implementaciones futuras para esta app:
 📍 Mejorar el acceso a la aplicación mediante verificación de usuarios para cada sesión
 📍 Añadir sección de trailers para cada peli 
 📍 Mapa de cines o plataformas de reproducción

## Getting Started

This project is a starting point for a the Flutter application Stackflix.

This app was born as a consolidated base of the StackMusical app. 
Its main function is to be able to access it through the interface developed in Dart:Flutter 
to the movie catalog of the TheMovieDataBase API, thus allowing 
to add and save favorite or recent movies to movie billboards to a local database. 

Some of the future implementations for this app: 
📍 Improve the access to the application by verifying users for each session 
📍 Add trailer section for each movie 
📍 Map of cinemas or playback platforms
